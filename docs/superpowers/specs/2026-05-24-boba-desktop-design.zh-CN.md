# Boba 桌面版设计稿

## 目标

把 Boba 从一个只能被 Codex / Petdex 显示的宠物，扩展成一个可以在 Windows 桌面常驻的小伙伴。

第一版重点不是做复杂面板，而是实现这些轻量能力：

- 开机后可以自动启动。
- 桌面上有一个透明悬浮的 Boba。
- 可以用鼠标拖拽移动。
- 可以右键打开中文菜单。
- 可以双击查看当前状态。
- 可以读取现有 `boba` 命令写出的状态文件，并用中文气泡提醒。

这版桌面程序不替代 Claude Code、Codex，也不替代已经做好的 `boba` CLI。它只负责显示和交互。

## 技术方案

第一版使用 Electron。

选择 Electron 的原因：

- Windows 上实现透明悬浮窗口比较直接。
- 支持右键菜单、鼠标事件、拖拽窗口。
- 支持开机自启动。
- 可以直接读取本地 JSON 状态文件。
- 可以复用当前 Node.js 项目里的代码。

## 第一版体验

### 悬浮宠物窗口

Boba Desktop 会显示一个小型透明悬浮窗口。

行为：

- 默认置顶显示。
- 无边框、透明背景。
- 鼠标左键拖拽可以移动。
- 记住上次位置，下次打开时恢复。
- 状态更新时不抢焦点。
- 可以通过右键菜单退出。

第一版可以先使用一个简单的 Boba 视觉形象。后续再接入 Petdex 的 `spritesheet.webp` 做动画。

### 鼠标交互

第一版支持：

- 左键拖拽：移动 Boba。
- 双击：显示当前状态气泡。
- 右键：打开中文菜单。
- 悬停：第一版暂不做额外效果，避免打扰。

交互原则是轻，不挡工作，不频繁弹出东西。

## 右键菜单

右键菜单使用中文：

- 在这里打开 Codex
- 在这里打开 Claude
- 查看当前状态
- 开机自动启动：已开启 / 已关闭
- 退出

菜单行为：

- `在这里打开 Codex`：启动 `boba codex`。
- `在这里打开 Claude`：启动 `boba claude`。
- `查看当前状态`：立即显示当前状态气泡。
- `开机自动启动`：切换是否随系统启动。
- `退出`：关闭 Boba Desktop。

第一版如果无法判断当前项目目录，就默认在用户主目录启动 Codex / Claude。以后可以加“选择项目目录”。

## 状态文件

Boba Desktop 读取已有状态文件：

```text
~/.boba-agent-coach/state.json
```

读取规则：

- 文件不存在：显示待命状态。
- 文件格式错误：显示待命状态，不崩溃。
- 遇到未知状态：显示待命状态。
- 默认每 2 秒读取一次。

## 中文提示文案

桌面版根据 `messageKey` 显示中文：

```text
agent_running -> Agent 正在工作。
agent_waiting_for_user -> Agent 好像在等你下一步。
task_may_be_stuck -> 这一步可能卡住了，要不要看一下最近输出？
task_ready_to_wrap_up -> 看起来可以收尾了：总结、提交，或者记录结果。
```

如果没有 `messageKey`，就根据 `status` 兜底：

```text
running -> Agent 正在工作。
waiting_for_user -> Agent 好像在等你下一步。
stuck -> 这一步可能卡住了，要不要看一下最近输出？
ready_to_wrap_up -> 看起来可以收尾了：总结、提交，或者记录结果。
```

默认待命文案：

```text
Boba 正在待命。
```

启动失败时显示：

```text
启动失败，请检查 boba 命令是否可用。
```

## 视觉状态

第一版定义 5 种状态：

- `idle`：待命。
- `working`：Agent 正在运行。
- `gentle_prompt`：Agent 可能在等你。
- `concerned`：任务可能卡住。
- `settled`：任务可能可以收尾。

第一版可以用气泡颜色、文字和简单 CSS 来区分这些状态。完整动画留到后续。

## 开机自启动

Boba Desktop 支持开机自启动。

规则：

- 右键菜单里可以开启或关闭。
- 菜单文字要显示真实状态。
- 设置失败时不退出程序，只显示中文错误提示。

## 本地配置

Boba Desktop 单独保存自己的设置，不写入 `boba-agent-coach` 的状态目录。

建议路径：

```text
~/.boba-desktop/config.json
```

配置示例：

```json
{
  "windowPosition": { "x": 1200, "y": 680 },
  "launchAtLogin": true
}
```

如果配置文件不存在或损坏，使用默认值，并在下次保存时重新创建。

## 错误处理

如果找不到 `boba` 命令：

- 打开 Codex / Claude 的菜单动作显示错误气泡。
- 桌面宠物继续运行。

如果状态文件读不了：

- 回到待命状态。
- 不反复弹错误。

如果启动 Codex / Claude 失败：

- 显示：`启动失败，请检查 boba 命令是否可用。`
- 程序不崩溃。

## 测试方式

自动测试：

- `messageKey` 到中文文案的映射。
- `status` 到中文文案的兜底映射。
- 配置文件不存在或损坏时的行为。
- 状态文件不存在或损坏时的行为。

手动验证：

- 启动 Boba Desktop，确认悬浮窗口出现。
- 拖动窗口，重启后位置保持。
- 右键菜单出现，且全部是中文。
- 开启 / 关闭开机自启动，菜单状态正确变化。
- 写入不同的 `state.json`，确认中文气泡更新。
- 双击 Boba，确认显示当前状态。
